# 公众号发布 SOP（使用本工具）

## 每次发布 4 步

```bash
# 1. 质检（用配套工具，可选但强烈建议）
node ../x-article-factory/bin/xaf.mjs check 文章.md

# 2. 看计划
node bin/wxpub.mjs publish 文章.md --dry-run

# 3. 推进草稿箱
node bin/wxpub.mjs publish 文章.md --theme blue

# 4. 后台手工三步
#    勾原创 → 创作来源选「个人观点，仅供参考」→ 点发布
```

## 改稿不新建

```bash
node bin/wxpub.mjs publish 文章.md --update <media_id>
```

`media_id` 在第一次推送的输出里。

⚠️ **注意顺序**：`--update` 会覆盖草稿内容，可能重置后台已设的原创/合集。所以定稿后再设后台项。

## 文末引导写什么

建议结构（配置里一次配好）：

| 段落 | 作用 |
|---|---|
| 出处说明 | 内容来自哪里（公开资料/社群/自己的实践） |
| 关于我 | 一句自我介绍，比"关于本号"有人味 |
| 这条路径 | 引导去合集，说明系列顺序 |
| 最后一句 | 不喊关注，留一句"留言区随时聊" |

## 发布检查清单

```
[ ] 封面标题没被裁（内容在上 1/3）
[ ] 摘要通顺（不是半句话）
[ ] 9 张图都在正确位置
[ ] 列表没有空项目符号
[ ] 文末引导完整
[ ] 原创已勾
[ ] 创作来源已选
[ ] 合集已加（或发布后批量加）
```
